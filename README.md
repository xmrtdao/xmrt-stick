# XMRT Stick

A Fire-Stick-style HDMI device that plugs into any TV and instantly turns it into a Monero-mining, meshnet-ready, AI-agent-powered XMRT node.

## What Is It?
- **Hermes Agent** built-in — runs the MobileMonero fleet agent locally
- **XMRig mining** — silent background hash production
- **LoRa meshnet** — off-grid communication via LoRa radios
- **WiFi 6 + USB/HDMI** — plug-and-play on any modern display
- **Open source** — hardware schematics and firmware are fully open

| Storage | 64 GB eMMC + MicroSD |
| Connectivity | WiFi 6, BT 5.3, LoRa 868/915 MHz |
| Ports | HDMI 2.1, USB-C, USB-A 3.0 |
| Power | 5V/2A USB-C |
| Dimensions | 85 x 30 x 12 mm |

| Expected MSRP | $89 USD |
