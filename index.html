XMRT Stick

Plug-in privacy. A Fire-Stick-style device that turns any TV into a Monero-mining, meshnet-ready, AI-agent-powered node. Built by XMRT DAO.
Explore Features View on GitHub

What It Does

Hermes Agent Onboard

Built-in MobileMonero fleet agent runs locally on the Stick. Control your mesh, mine, and chat with the DAO — no external laptop required.

XMRig Mining

Silent, efficient Monero mining while your TV is idle. Configurable pools and automatic fleet orchestration.

LoRa Meshnet

Off-grid communication via LoRa. Join the XMRT mesh, relay messages, and stay connected even without internet.

WiFi + USB/HDMI

Plug directly into any HDMI port. USB power, onboard WiFi, and optional Ethernet for maximum flexibility.

Open Source

Firmware, hardware schematics, and agent config are fully open. Flash your own image or run ours.

Fleet Dashboard

See your Stick's status on relay.mobilemonero.com alongside the rest of your XMRT fleet.
